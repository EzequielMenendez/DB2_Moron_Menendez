## Análisis del caso más significativo de imprecisión de la IA
El caso más significativo ocurrió en la **Parte A**, cuando la IA sugirió otorgar `GRANT ALL PRIVILEGES ON DATABASE food_store TO app_web;` para simplificar la configuración de permisos. Si el equipo hubiera aceptado esta propuesta de forma acrítica, el rol de aplicación web habría obtenido privilegios de propietario/superusuario sobre la base, vulnerando por completo el **principio de mínimo privilegio**. Este error se detectó mediante la lectura crítica del script de roles antes de ejecutarlo, recordando que una aplicación web solo debe tener acceso operativo de lectura e inserción/actualización acotada, nunca privilegios DDL o de administración.
